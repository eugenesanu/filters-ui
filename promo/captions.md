# FiltersUI captions

One block per video in `videos/`. Each has a Dribbble title and description, an X post and an on.design post, and each ends on the filter's own page. Dribbble and X take the 4K file as it is (3840 x 2880, 60 fps, HEVC); on.design gets an H.264 copy made from it.

Dribbble tags for all of them: filters, search, ui components, react, tailwind, open source, dark ui, product design
